# Agua Eucalipto

Lista vecinal de folios y pipas de la calle Eucalipto, en piloto.

## Cómo correrlo

Instala las dependencias:

```bash
npm ci
```

Arranca el servidor de desarrollo:

```bash
npm run dev
```

Ejecuta las pruebas:

```bash
npm test
```

Construye el sitio:

```bash
npm run build
```
